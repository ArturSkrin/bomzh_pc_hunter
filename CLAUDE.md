# Baraholka bot

Бот ищет на румынских барахолках дешёвое/бесплатное/выгодное компьютерное железо,
присылает лоты в Telegram и помогает торговаться с продавцами.

## Что ищем (модель работы)
- Ничего не ремонтируем и не восстанавливаем. Три сценария: собрать готовый ПК из дешёвых рабочих комплектующих
  и продать; перепродать то, что продавец отдаёт ниже рынка; забрать в хоумлаб (серверы, мини-ПК, Xeon, ECC, диски, NAS)
- Цели: готовые ПК, десктопные CPU, материнки, RAM, видеокарты, диски, БП, ноуты — если дёшево
- Битое / «на запчасти» — не берём (отсекается и правилами, и нейронкой)

## Архитектура
- Python 3, httpx, selectolax (для HTML-сайтов), SQLite (позже Postgres)
- Сборщик 3 раза в день (по умолчанию 09:00, 14:00, 20:00, каждое ±10 мин), время правится в веб-морде;
  паузы между запросами, дедуп по ID объявления
- Фильтр: сначала правила (цена, ключевые слова; мусор — по заголовку), потом LLM оценивает выгодность 0–10
  глазами перекупа; в Telegram — только от порога (llm_min_score, по умолчанию 5). Промпт правится в веб-морде,
  формат ответа зашит в коде
- LLM через LiteLLM (провайдер меняется конфигом), ключи в .env
- Telegram-бот: карточка лота (фото, цена, оценка, ссылка) + кнопки
  «Уточнить», «Торговаться до X», «Пропустить»

## Торг — этап 1 (сейчас): режим черновиков
- Бот пишет сообщение продавцу на румынском, я отправляю сам вручную
- Первое сообщение — уточнение (модель, конфиг, рабочее ли), потом оценка по похожим объявлениям
- Ответы продавца пересылаю боту, он предлагает следующую реплику
- Где: страница лота в веб-морде (`/listing/<id>`, «💬 торг»: переписка, «торгуюсь до X», копировать) и Telegram
  (кнопка → черновик; reply на карточку/черновик текстом продавца → следующая реплика, лот по метке `#lotN`)
- Черновик с нарушением правил — одна попытка переписать, иначе показывается с ⚠️
- Автоотправка (Playwright) — только этап 2, не делать без моей команды

## Жёсткие правила (в коде, не в промпте)
- Потолок цены, который агент не может превысить
- Никакой предоплаты и «оплаты по ссылке» (OLX Livrare с онлайн-оплатой тоже). Курьер — только ramburs
  (оплата при получении, лучше с deschiderea coletului)
- Адрес/телефон/встречу — только я
- Без выдуманных аргументов при торге
